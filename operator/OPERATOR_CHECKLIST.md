# CourtVision 🎾 — Operator Routine Checklist

Use this operational checklist before, during, and after every sports match broadcast.

---

## 📋 Operational Phase Checklists

### Phase 1: Pre-Match Setup (15 Minutes Before Match)
- [ ] Stationary camera tripod is securely locked in position.
- [ ] USB or network Ethernet cable is firmly connected.
- [ ] Windows PC is booted and CourtVision is launched.
- [ ] Active Court Profile (e.g. `Court 1`) is selected.
- [ ] Court calibration (`⚙ CALIBRATE COURT`) verified or updated.
- [ ] Sponsor graphics loaded and opacity set (`0.85`).
- [ ] Live preview checked: player occlusion working cleanly.

### Phase 2: Live Match Execution
- [ ] Click **🔴 RECORD VIDEO** at match start.
- [ ] Green recording status confirmed.
- [ ] Monitor Stream Health bar for FPS and connection status.
- [ ] Execute live sponsor ad switches during mid-match timeouts if required.

### Phase 3: Post-Match Shutdown
- [ ] Click **⏹ STOP RECORDING** at match end.
- [ ] Verify output MP4 exists in `output/`.
- [ ] Stop camera preview cleanly.
- [ ] Close CourtVision.
